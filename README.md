# Kinnex

동의한 가족과 위치를 나누는 서비스입니다. 웹사이트는 회사 소개만 두고, 가족 지도는 휴대폰 앱에서 씁니다.

제품 이름은 **Kinnex** 입니다. GitHub 저장소는 [jadegun1124/umap](https://github.com/jadegun1124/umap) 입니다.

## 화면

- 웹(GitHub Pages): 회사 홈페이지. 관제 콘솔은 없습니다.
- 앱: Capacitor 안드로이드 앱이 가족 위치 화면을 엽니다. 브라우저에서 같은 화면을 보려면 `?app=1` 을 붙입니다.

흐름은 카카오·네이버·복구 코드로 불러오기 또는 새로 시작 → 새 계정이면 표시 이름 → 권한 안내 → 가족 지도입니다. 이미 있는 계정은 이름·가족·기록을 그대로 불러옵니다. 가족 방의 구성원은 같은 역할입니다. 하단 탭 없이 지도만 둡니다. 움직이는 동안 메인 지도에 아직 기록으로 넘기지 않은 궤적을 그립니다. 걸음은 5분, 시속 약 7km 이상은 12분 머물면 그 구간은 기록으로 넘어가고 메인 선에서는 빠집니다. 기록을 닫아도 아직 이동 중인 선은 메인 지도에 남습니다. 메뉴의 움직임 알림에서 고른 가족에게만, 내가 움직이기 시작하거나 멈출 때 짧은 알림을 보냅니다. 아무도 고르지 않으면 보내지 않습니다. 왼쪽 위 메뉴에서 프로필, 우리 집, 알림, 초대 수락, 설정을 엽니다. 사람을 한 번 누르면 그 사람의 현재 위치로 지도가 이동하고 이름이 보입니다. 같은 사람을 한 번 더 누르면 기록이 열립니다. 다른 사람을 누르면 그 사람으로 옮기고, 빈 지도를 누르면 선택이 풀립니다. 기록은 전체 화면이고 날짜는 오늘이 기본이며 누르면 30일 목록이 열립니다. 알림 종은 지도 위에도 있습니다. 누구나 가족을 초대하고 받은 초대를 수락합니다. 위치 공유는 권한 안내를 마치면 허용되고, 이미 허용한 뒤에는 메뉴와 설정에 끄는 토글을 두지 않습니다.

## 권한

앱이 설명한 뒤에만 요청합니다.

| 권한 | 쓰는 이유 |
| :--- | :--- |
| 알림 | SOS와 집 반경. 처음 권한 화면에서 위치와 함께 묻고, 허용을 누르면 시스템 알림 창이 열립니다. 위치 공유 중에는 알림 목록에 Kinnex 카드를 올리지 않습니다. |
| 위치 | 정확한 위치 또는 대략적인 위치. 앱 사용 중은 위치 권한 창, 항상 허용은 이 앱의 위치 액세스 권한 화면을 먼저 엽니다. 그 화면이 열리지 않으면 앱 권한 목록으로 갑니다. 로그인한 뒤 항상 허용과 정확한 위치가 아니면 안드로이드 앱 전체를 막는 안내가 뜹니다. |
| 움직임 | 안드로이드 신체 활동 권한 창. 다시 물을 수 없으면 설정으로 이동합니다. |
| 배터리 | 배터리 제한 없음을 누르면 시스템 팝업이 바로 열립니다. 스위치는 직접 고릅니다. |
| 카메라 | 초대 QR을 읽을 때만. 허용을 누르면 카메라 권한 창이 열리고, 다시 물을 수 없으면 설정으로 갑니다. 스캔이 끝나면 끄고, 마이크와 전화번호는 읽지 않습니다. |

마이크, 문자, 주변 소리, 원격으로 소리를 울리는 기능은 없습니다. 전화번호만으로 다른 사람을 찾지 않습니다.

항상 허용을 누르면 `ACTION_MANAGE_APP_PERMISSION`과 `android.permission-group.LOCATION`으로 삼성 권한 컨트롤러의 `ManagePermissionsActivity`(「위치 액세스 권한」: 항상 허용, 앱 사용 중에만, 정확한 위치 사용)를 바로 엽니다. 그 화면이 열린 뒤에는 앱 정보로 덮지 않습니다. 그 액티비티가 없을 때만 앱 권한 목록, 그다음 앱 정보로 갑니다. 앱 안 안내는 세 줄입니다. 「항상 허용」 고르기, 「정확한 위치 사용」 켜기, 배터리 제한 없음. 앱은 OS 스위치를 대신 바꾸지 않습니다. 배터리 제한 없음을 누르면 `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` 팝업이 바로 열립니다.

### 알림 목록

1.6.0은 위치 포그라운드 서비스와 SOS 대기 포그라운드 서비스가 `startForeground`로 알림을 올렸습니다. 제목과 본문은 빈 문자였고 채널 중요도는 최소였습니다. 안드로이드 12 이상은 포그라운드 서비스 알림을 중요도와 상관없이 알림 목록에 남깁니다. 삼성 One UI는 그 빈 알림을 앱 아이콘만 있는 카드로 접고, 같은 앱의 두 번째 알림을 "1개 알림 더보기"로 묶습니다. 채널 이름을 바꿔도 서비스가 다시 `startForeground`를 호출하면 카드가 돌아옵니다.

1.7.0은 그 포그라운드 서비스를 쓰지 않습니다. 항상 허용 뒤 `LocationManager` PendingIntent로 위치를 받습니다. 이 경로에는 알림 객체가 없습니다. 앱을 열면 예전 채널 `umap_location`, `umap_location_quiet`, `umap_alert_watch`와 알림 id 4108·5108을 지웁니다. SOS와 집 반경은 `umap_alert`(가족 알림, 높은 중요도)로 올립니다. 새 대화는 `umap_chat`(가족 대화)으로, 보낸 사람 이름과 짧은 내용만 올립니다. 둘 다 사건이 있을 때만 뜨고 상시 카드는 아닙니다. 알림 대기는 정확한 알람으로 약 12초마다 읽고, 대기 중에는 카드를 올리지 않습니다. 대화 알림을 누르면 그 대화가 열립니다.

상태 표시줄의 위치 사용 아이콘은 시스템 표시라 앱이 지울 수 없습니다. 배터리 제한 없음이 아니면 안드로이드 8 이상의 백그라운드 위치 제한으로 갱신이 한 시간에 몇 번으로 줄어들 수 있습니다. 절전 중이고 정확한 알람이 없으면 SOS 대기는 더 띄엄띄엄 일어납니다. 포그라운드 서비스 알림을 다시 띄우면 안드로이드 12 이상에서 Kinnex 카드가 다시 생깁니다.

## 이름과 지도

키는 환경 변수로만 넣습니다. 로컬에서는 `.env.example` 을 복사해 `.env` 를 만들고 `VITE_VWORLD_API_KEY=` 뒤에 키를 적습니다. `.env` 는 gitignore 되어 있어 커밋되지 않습니다.

```bash
VITE_VWORLD_API_KEY=
VITE_FAMILY_SYNC_URL=
```

- 이름: 가족 지도에 보일 표시 이름과 프로필 사진을 이 기기에서 정합니다. 가족 서버에 연결되면 같은 초대의 다른 폰에도 보입니다. 카카오·네이버 또는 복구 코드로 다시 설치해도 같은 사람과 가족 방을 불러옵니다. 전화번호 본인 확인은 없습니다.
- 지도: 국토교통부 [VWorld](https://www.vworld.kr/) 2D Base 한 종류입니다. 위성, CARTO, OpenStreetMap 전환은 없습니다.
  - `https://api.vworld.kr/req/wmts/1.0.0/{API_KEY}/Base/{z}/{y}/{x}.png`
  - 키는 `import.meta.env.VITE_VWORLD_API_KEY`만 읽습니다. 빌드 시점에 JS 안에 들어갑니다.
  - 키가 없으면 "키가 이 빌드에 없습니다"만 보여 주고 타일을 요청하지 않습니다. 키가 있는데 타일이 실패하면, 그 페이지의 주소(origin)를 인증키 도메인에 넣으라는 안내가 나옵니다. 타일이 한 장이라도 오면 안내는 사라집니다.
  - 인증키 서비스 URL: `https://jadegun1124.github.io`, 앱 `https://localhost`, 로컬 개발 `http://localhost:5173`.
  - 가족 카드의 현위치는 「구리시 수택동 · 지금」, 「남양주시 다산동 · 머무름」처럼 시·동과 상태다. VWorld 주소가 우선이고, 키가 없거나 실패하면 Nominatim으로 같은 형식의 주소를 채운다. 「근처」는 쓰지 않는다.
- 이동 경로: 서울 날짜로 오늘부터 30일 전까지 이 기기에 남기고, 그보다 오래된 점은 지웁니다. 정지는 반경 50m·3분, 구간은 정지와 정지 사이의 이동 시간입니다. 걷는 동안에는 약 4m마다 점을 남겨 골목을 따라 굽습니다. 화면에서 선을 펴는 거리는 1.8m라, 정확도가 ±15m여도 곡선이 한 줄로 붙지 않습니다. 32m보다 긴 현에는 실제로 걷던 중간 점을 다시 넣습니다. 머무름 중 건물 주변 흔들림은 잇지 않습니다. 정확도가 나쁜 점과 시속이 거의 0인 점이 약 220m 안에 있으면 빼고, 그 구간은 한 점으로 모읍니다. 갔다가 바로 돌아오는 얇은 스파이크도 잇지 않습니다. 이 폰의 선과 다른 폰에서 받은 선이 같은 기준입니다. 이어진 걸음은 실선이고, 48m 이상 비고 20초 이상 점이 없는 구간만 점선입니다. 그 빈 구간을 도로 모양으로 채우지 않습니다. 실시간 핀은 체류 반경을 벗어나면 그 위치로 이동합니다. 위치 유지를 켠 폰은 걸음이 확인되면 GPS를 2초마다, 시속 약 7km 이상이면 1초마다 받습니다. 머무는 동안은 20초마다 움직임만 확인하고 점은 남기지 않습니다. 가족 업로드는 이동 중 30초, 머무름 중 60초이고, 상태가 바뀌면 바로 보냅니다. 시속 약 7km 이상의 점은 1초마다 받은 위치로 실선을 잇고, 속도만 빠르고 움직이지 않은 값은 선에 넣지 않습니다. 걸음은 5분, 차량은 12분 머물면 그 구간을 기록으로 넘깁니다. 걸음 뒤 45초, 차량 뒤 3분이 지나기 전에는 가족 카드를 「머무름」으로 바꾸지 않습니다. 가족 카드는 그 이동 동안 「지금」입니다. 가족 카드에는 「방금 업데이트」 또는 「3분 전 업데이트」처럼 마지막 시각을 적습니다. 유료 도로 스냅은 쓰지 않습니다. 샘플 사람이나 예시 좌표는 없습니다.

`VITE_GOOGLE_MAPS_API_KEY`는 가족 지도에서 쓰지 않습니다.

GitHub Actions secret `VITE_VWORLD_API_KEY`와 `VWORLD_API_KEY`는 같은 값입니다. Pages 워크플로(`deploy.yml`)와 APK 워크플로(`build-apk.yml`)가 `npm run build`에 `VITE_VWORLD_API_KEY`를 넘깁니다. Vite용 secret이 비어 있으면 `VWORLD_API_KEY`를 그 이름으로 복사한 뒤 공백을 지웁니다. 로그에는 키가 있는지 여부만 남기고 문자열은 찍지 않습니다. secret을 바꾸면 `main`에 푸시해 두 워크플로를 다시 돌려야 배포된 Pages와 APK에 들어갑니다. PR 검사만으로는 키가 들어가지 않습니다. 로컬은 gitignore된 `.env`에 `VITE_VWORLD_API_KEY=`를 둡니다.

## 아이콘

승인된 마크는 남색에서 시안으로 이어지는 파란 타일과 흰 위치 핀이다. 핀 안에는 파란 고리와 흰 점이 있다. 원본은 `resources/icon.svg` 벡터다.

- 웹 파비콘과 PWA 아이콘(192/512, maskable 포함): `public/`
- 안드로이드 런처(레거시 사각형·원형), 적응형(그라데이션 배경 + 안전 영역 핀), 모노크롬, 알림 작은 아이콘, 스플래시: `android/app/src/main/res/`
- iOS 앱 아이콘과 스플래시 세트: `resources/ios/`
- 잘라 둔 래스터: `resources/icon-master.png`
- 다시 쓰기: `python3 scripts/render-umap-icon.py`
- 흰 여백이 있는 그림에서 그라데이션만 다시 뽑으려면 `python3 scripts/render-umap-icon.py 원본.jpg`

이 저장소에는 아직 Xcode 프로젝트가 없습니다. `resources/ios` 는 Capacitor iOS를 추가하기 전에 둔 에셋입니다. `ios/` 폴더를 미리 만들어 두면 `cap add ios` 가 막히므로 거기에 두지 않았습니다.

## 로컬 실행

```bash
npm ci
npm run dev
```

회사 홈은 `/`, 앱 화면은 `/?app=1` 입니다. `/?app=1&reset=1` 은 이 브라우저에 저장된 가족 세션을 지웁니다.

## 안드로이드 APK

받는 곳: https://github.com/jadegun1124/umap/releases/download/v1.63.0/kinnex-v1.63.0.apk

`main` 푸시마다 `Build Android APK (Kinnex)` 워크플로가 웹을 빌드하고 `dist` 를 안드로이드 에셋으로 복사한 뒤 `assembleRelease` 로 APK를 만듭니다. 서명은 `android/app/umap-sideload.keystore` 이고 SHA-1은 `00:57:37:35:22:70:B8:4C:7F:B6:01:61:29:BD:A9:A3:CD:09:35:0C` 입니다. 결과 파일은 GitHub Release `v1.63.0`에 올립니다. 앱 `versionName`은 `1.63.0`, `versionCode`는 69입니다. Play 스토어 트랙은 없습니다.

1.16.0까지 그 빌드는 러너마다 새로 만든 디버그 키로 서명했습니다. 패키지가 `kr.co.umap.tracker`여도 인증서가 다르면 안드로이드는 덮어쓰기를 거절해서, 지우고 다시 깔아야 했습니다. 1.17.0부터 debug와 release는 저장소의 `android/app/umap-sideload.keystore`(별칭 `umap-sideload`)로 서명합니다. 비밀번호는 `android/app/build.gradle`에 있습니다. 인증서 SHA-256은 `4A:15:08:0F:72:C3:87:D1:E8:50:A8:DE:5A:89:34:9A:B4:1A:48:0D:C5:97:71:AB:22:9C:85:44:C8:61:7A:6C`입니다. 이 키는 가족 폰에 직접 설치하는 사이드로드 전용이고, Play 앱 서명 키가 아닙니다.

업데이트는 새 APK를 받아 기존 앱 위에 설치합니다. 지우지 않으면 이 폰의 데이터가 남습니다. 예전 디버그 키로 깔린 1.16.0 이하는 서명이 달라 한 번은 지운 뒤 1.17.0 이상을 설치해야 합니다. 그 다음 빌드부터는 지우지 않고 이어서 업데이트됩니다.

## 계정 로그인

첫 화면은 카카오, 네이버, 복구 코드로 불러오기, 새로 시작입니다. 서버에 이미 있는 계정은 표시 이름과 가족, 기록을 그대로 불러오고 이름을 다시 묻지 않습니다. 새 계정이면 그 다음에 표시 이름을 묻습니다. 카카오·네이버 또는 복구 코드는 다시 설치한 뒤 같은 구성원 id와 가족 방, 최근 30일 기록을 불러옵니다. 설정 「로그아웃」은 서버 백업을 남깁니다. 설정 「회원 탈퇴」는 서버 계정, 기록, 카카오·네이버 연결, 복구 코드를 지웁니다. 제3자 제공 기록은 개인정보 값과 좌표 없이 6개월이 지난 뒤에 지웁니다. 설정에 「정보 제공 기록」이 있습니다. 여러 로그인을 한 계정에 연결할 수 있습니다. 버튼만 누르고 통과하지 않습니다. 해당 키가 없으면 그 버튼은 비활성으로 두고 한국어 설정 안내만 보여줍니다. Google 로그인은 쓰지 않습니다. 예전 계정 레코드에 google 필드가 있어도 Worker는 무시하고 깨지지 않습니다.

### 카카오 로그인

무료 카카오 로그인만 씁니다. Worker는 액세스 토큰을 `https://kapi.kakao.com/v1/user/access_token_info`와 `https://kapi.kakao.com/v2/user/me`로 확인하고, 카카오 사용자 id로 같은 계정을 찾습니다. 이 폰에 이미 계정이 있는데 그 카카오가 다른 계정에 연결되어 있으면, 앱은 기존 가족 방을 이 계정으로 가져올지 묻습니다. 가져오기는 이 폰의 세션과 방금 확인한 카카오 토큰이 둘 다 있을 때만 됩니다. 암호화된 지난 기록은 가족 폰이 이 폰의 열쇠로 다시 감싸거나, 기록 화면에 예전 복구 코드를 입력하기 전에는 열리지 않습니다.

1. [Kakao Developers](https://developers.kakao.com/) → 내 애플리케이션 추가 → **카카오 로그인** 활성화.
2. 네이티브 앱 키 `b42233e0170711205fa75bbca06e98e9` 는 공개 값이라 앱에 들어 있습니다. 환경 변수 `VITE_KAKAO_NATIVE_APP_KEY` 또는 `KAKAO_NATIVE_APP_KEY`가 있으면 그 값이 우선입니다. 웹 로그인은 **JavaScript 키** `VITE_KAKAO_JAVASCRIPT_KEY`가 있을 때만 열립니다. 그 키는 아직 앱에 없습니다.
3. 플랫폼 → Android. 패키지 이름 `kr.co.umap.tracker`. 키 해시 `AFc3NSJwuEx/tgFhKb2po80JNQw=` (사이드로드 SHA-1 `00:57:37:35:22:70:B8:4C:7F:B6:01:61:29:BD:A9:A3:CD:09:35:0C`의 Base64).
4. 플랫폼 → Web. 사이트 도메인 `jadegun1124.github.io`. Redirect URI 스킴은 `kakao{네이티브앱키}://oauth` 입니다. 카카오 계정으로 로그인, 닉네임만 받으면 됩니다.

### 네이버 로그인 (네아로)

무료 네아로만 씁니다. 앱은 Client ID와 인가 코드만 보내고, Client Secret은 Worker에만 둡니다. Worker는 `https://nid.naver.com/oauth2.0/token`으로 코드를 바꾼 뒤 `https://openapi.naver.com/v1/nid/me`로 확인하고, 네이버 id로 같은 계정을 찾습니다.

1. [Naver Developers](https://developers.naver.com/apps/#/register) → 애플리케이션 등록 → 사용 API **네아로(네이버 로그인)**.
2. 로그인 오픈 API 서비스 환경 **Android**. 패키지 이름 `kr.co.umap.tracker`.
3. 다운로드 URL `https://github.com/jadegun1124/umap/releases/download/v1.63.0/kinnex-v1.63.0.apk`. 설정 화면의 앱 업데이트는 버전과 상관없이 `https://github.com/jadegun1124/umap/releases/latest` 를 엽니다.
4. Callback URL은 `https://umap-family-sync.umap-jadegun.workers.dev/v1/naver/callback` 입니다. Worker가 그 주소를 `kinnex://naver` 로 돌려 앱이 인가 코드를 받습니다. 웹은 `https://jadegun1124.github.io/kinnex/` 와 `http://localhost:5173/` 입니다.
5. Client ID `dQCiRLIzbNkDG6ULiroD` 는 공개 값이라 앱과 Worker `NAVER_CLIENT_ID`에 들어 있습니다. `VITE_NAVER_CLIENT_ID`가 있으면 그 값이 우선입니다.
6. Client Secret은 `npx wrangler secret put NAVER_CLIENT_SECRET`으로만 Worker에 넣습니다. 앱, 저장소, APK에 넣지 않습니다. 비밀이 없으면 Worker는 네이버 로그인을 거절하고 `NAVER_CLIENT_SECRET`이 없다고 알립니다.

카카오 사용자 id와 네이버 id는 구성원 ID가 되지 않습니다. 같은 계정 또는 복구 코드로 다시 들어오면 Worker에 저장된 `local-` ID와 방 키를 다시 씁니다.

## 데이터

안드로이드 `allowBackup`은 false입니다. 클라우드 백업과 기기 간 이전 규칙은 모든 도메인을 뺍니다. 앱 업데이트는 이 폰의 데이터를 지우지 않습니다. 앱을 지우고 다시 깔면 카카오·네이버 또는 복구 코드로만 돌아옵니다.

가족, 우리 집 반경, 권한, 위치 공유 허용은 이 탭의 `sessionStorage`와 `localStorage`(`umap_family_v1`)에 있습니다. 예전 관리자·피관리자 저장은 열 때 한 가족으로 합칩니다. 구성원은 그대로 남고, 이 기기가 올린 위치는 「관리자」라는 다른 사람이 되지 않습니다.

같은 브라우저에서 위치 공유를 허용하면 그 좌표가 `umap_family_places_v1`로 가족 핀에 붙습니다. 다른 폰은 초대 링크의 동기화 키로 가족 위치 서버에 최신 위치와 배터리를 올리고, 같은 가족 방이 그 서버에서 받아 지도와 목록에 표시합니다. 예시 좌표나 하드코딩된 팝업이 아닙니다. 서버가 없거나 끊기면 같은 브라우저 공유만 남고, 화면에 그 사실을 한국어로 알립니다. SOS와 집 반경 알림은 같은 가족 방에 전달됩니다. 알림을 허용하면 앱이 꺼져 있어도 Web Push 또는 알림 대기로 SOS를 받습니다. 개인 대화도 받는 사람의 알림 목록에 보낸 이름과 짧은 내용으로 옵니다. 브라우저가 Push를 구독할 수 있으면 Web Push이고, 이 앱의 WebView처럼 Push가 없으면 알림 대기가 대화를 읽어 올립니다. 문자는 쓰지 않습니다. 전화번호로 위치를 찾지 않습니다.

## 다른 폰과 위치 나누기

초대를 만들 때와 받을 때 **위치 공유 허용**을 묻습니다. 이미 공유 중이면 다시 묻지 않고 그 방에도 바로 나갑니다. 허용하면 지금 공유가 시작되고 앱을 다시 열어도 유지됩니다. 나중에를 고르면 내 위치는 나가지 않고, 가족 목록에서 다시 허용할 수 있습니다. 메뉴에는 위치 공유 항목이 없습니다. 전화번호는 이 동기화에 쓰지 않습니다.

가족 지도는 초대 코드와 이름으로 핀을 맞춥니다. 코드가 같고 이름이 같거나, 그 코드의 구성원이 한 명이면 붙습니다. 이 맞추기는 `apply-shared-place` 그대로입니다.

1. 관리자 폰이 쓰기 키와 읽기 키를 만듭니다. 읽기 키는 그 폰의 세션에만 있습니다.
2. 초대 링크에는 초대 코드, 쓰기 키, 읽기 키의 해시가 들어갑니다. 읽기 키 원문은 링크에 없습니다.
3. 위치 공유를 허용한 폰이 최신 점 하나를 `PUT /v1/rooms/{코드}/place` 로 보냅니다. 걷는 동안에는 5초마다, 머무름이 이어지면 30초 이상으로 다시 보냅니다.
4. 관리자 화면은 약 2.5초마다 읽기 키로 그 방을 읽습니다. 쓰기 키만 가진 폰은 좌표를 읽을 수 없습니다.
5. 집 이탈과 SOS도 같은 방으로 갑니다. 다른 폰의 관리자 화면에서 사이렌이 울립니다.
6. 서버에는 구성원 id별 최신 좌표와 최근 알림, 그리고 이름·썸네일 프로필이 있습니다. id가 없는 예전 점은 이름별로 남아 있고, 그 폰이 id를 보내면 같은 이름의 점을 id 슬롯으로 옮깁니다. 이동 경로 전체는 각 기기에만 쌓입니다. 프로필 수정은 그 기기의 프로필 키로만 됩니다.

같은 브라우저의 `localStorage`와 `BroadcastChannel`은 그대로 둡니다. 서버가 죽어도 그 경로로 같은 브라우저 안에서는 핀이 움직입니다.

### 주소와 배포

클라이언트에 넣는 값은 Worker 주소 하나입니다. API 비밀이 아니고, 빌드 결과물에 들어갑니다. 읽기 키와 Cloudflare 토큰은 넣지 않습니다.

공개 Worker는 이미 올라가 있습니다. Pages와 APK 빌드는 secret이 없어도 이 주소를 넣습니다.

```text
https://umap-family-sync.umap-jadegun.workers.dev
```

`deploy.yml`과 `build-apk.yml`은 Actions secret `VITE_FAMILY_SYNC_URL`이 있을 때만 그 값으로 바꿉니다. secret은 필수가 아닙니다. 로그에는 기본 주소인지, secret으로 바꿨는지만 남기고 다른 주소 문자열은 찍지 않습니다. 로컬 `npm run dev`는 gitignore된 `.env`의 `VITE_FAMILY_SYNC_URL`을 읽습니다. 그 값이 없으면 개발 서버는 같은 브라우저 공유만 합니다.

Worker를 다시 올릴 때만 Cloudflare에 배포합니다. 계정 토큰은 저장소에 커밋하지 않습니다.

```bash
cd sync
npx wrangler@4 login
npx wrangler@4 deploy
```

프로필은 `PUT /v1/rooms/:code/profile` 입니다. 본문에는 구성원 id, 이름, 작은 JPEG 또는 WebP 썸네일이 들어가고, 헤더 `x-umap-profile-key` 가 그 id의 주인만 고치게 합니다. 위치 `PUT /place` 에는 사진을 넣지 않고, 구성원 id가 있으면 같은 키로 그 슬롯만 갱신합니다. 이름을 바꿔도 id 슬롯의 최신 좌표는 남습니다.

개인 대화는 `POST /v1/rooms/:code/chat` 과 `GET /v1/rooms/:code/chat?me=&with=` 입니다. `me`만 있으면 그 이름이 참여한 대화만 돌아옵니다. 방 조회와 `GET /family`에는 글을 넣지 않습니다. 이 경로가 있는 Worker를 다시 올려야 다른 폰과 글이 오갑니다. 예전 Worker면 글은 이 기기에만 남고, 화면에 그 사실을 알립니다.

`sync/wrangler.toml`의 Workers Logs는 `head_sampling_rate = 0.1` 입니다. 샘플링은 요청이 시작될 때 정해지고, 오류만 100% 남기는 설정은 없습니다. 그래서 약 90%의 오류 호출도 Workers Logs에 남지 않습니다. 추적도 10%입니다. Workers Issues는 실패한 호출을 묶습니다. `npx wrangler deploy`는 이 파일을 읽습니다. Cloudflare scripts API로 multipart 업로드할 때는 메타데이터의 `observability.logs.head_sampling_rate`를 `0.1`로 넣어야 합니다. 이 저장소에는 그 메타데이터 파일이 따로 없습니다.

`sync/wrangler.toml`이 Durable Object `FamilyRoom`과 `FamilyAccount`를 만듭니다. 계정은 카카오 사용자 id, 네이버 id, 또는 복구 코드 해시로 구성원 id, 방 키, 최근 30일 여정·방문을 보관합니다. 무료 한도에서 관리자 화면 하나가 켜져 있으면 조회가 하루 약 3만 번을 넘습니다. 한도에 닿으면 `src/services/familySync.ts`의 폴링 간격을 늘립니다. Worker의 공개 변수는 `NAVER_CLIENT_ID` 입니다. 비밀은 `npx wrangler secret put NAVER_CLIENT_SECRET` 만 해당합니다.

### 두 기기로 확인

1. 폰 A와 폰 B에 같은 주소가 들어간 빌드를 설치합니다. `main`의 Pages와 APK는 `https://umap-family-sync.umap-jadegun.workers.dev` 를 기본으로 넣습니다.
2. 폰 A에서 관리자로 가족을 초대하고 **링크**를 보냅니다. 다섯 자리 코드만 보내면 같은 브라우저에서만 공유됩니다.
3. 폰 B에서 링크를 열고 가족으로 수락한 뒤 **위치 공유 허용**을 누릅니다. 위치 권한도 허용합니다.
4. 폰 A에 B의 핀이 나타나고, 위에 "다른 폰과 위치를 나누는 중"이 보입니다.
5. 폰 B에서 공유를 끄면 몇 초 안에 A의 핀이 사라집니다.
6. 집 반경이 들어 있는 링크로 들어온 뒤 그 원을 나가면 A에서만 이탈 사이렌이 울립니다. B의 SOS는 A에도 전달됩니다.

로컬에서 서버 경로는 브라우저 프로필 두 개로 볼 수 있습니다. 프로필이 하나면 `localStorage`가 먼저 전달하므로 다른 폰 경로가 아닙니다.

```bash
npm run sync
```

`.env`에 `VITE_FAMILY_SYNC_URL=http://127.0.0.1:8787` 을 넣고 `npm run dev` 한 뒤, `http://127.0.0.1:5173/?app=1` 을 프로필마다 엽니다. 서버를 끄면 노란 안내가 나오고 같은 브라우저 공유만 남습니다.

가족 궤적은 기록한 폰이 Worker `umap-family-sync`에 `PUT /v1/rooms/:code/trail`로 올리고, 다른 폰은 그 점과 여정을 그대로 그립니다. Worker 이름은 바꾸지 않습니다. 배포는 `sync` 디렉터리에서 `npx wrangler deploy` 입니다.
